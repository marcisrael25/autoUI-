Pourquoi adopter AutoUI ?

Zero Build Required[cite: 1]

Exemples Pratiques d'Utilisation

1. Web Component Personnalisé[cite: 1]

Étendez la classe AutoElement pour fabriquer des composants encapsulés réactifs[cite: 1]. 

import { AutoElement } from 'autoui-js';[cite: 1]

class UserCard extends AutoElement {[cite: 1]
    render() {[cite: 1]
        const name = this.getAttribute('name') || 'Membre';[cite: 1]
        return `
            <style>
                :host { display: block; padding: 15px; background: #12192c; border-radius: 8px; }
                .name { color: #00d2ff; font-weight: bold; }
            </style>
            <div class="name">${name}</div>
        `;[cite: 1]
    }[cite: 1]
}[cite: 1]

customElements.define('user-card', UserCard);[cite: 1]

3. Gestionnaire d'État (Store Réactif)[cite: 1]

Synchronisez vos données sur l'ensemble de votre interface graphique grâce à createStore[cite: 1]. 

import { createStore } from 'autoui-js';[cite: 1]

// Initialisation du Store Réactif
const store = createStore({ count: 0 });[cite: 1]

// Écouter les changements d'état
store.subscribe('count', (newVal) => {[cite: 1]
    console.log(`Valeur : ${newVal}`);[cite: 1]
});[cite: 1]

// Modifier l'état
store.count += 1;[cite: 1]
