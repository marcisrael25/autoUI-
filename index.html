Pourquoi adopter AutoUI ?

Développé pour la simplicité, la vitesse et l'élégance architecturale[cite: 1].

⚡

Zero Build Required[cite: 1]

Pas besoin de Webpack, Vite ou Babel[cite: 1]. Importez simplement la bibliothèque avec un seul tag CDN dans votre fichier HTML[cite: 1].

🔒

Encapsulation Shadow DOM[cite: 1]

Tous vos composants disposent de leurs propres styles CSS isolés pour éviter tout conflit avec vos styles globaux[cite: 1].

🔄

Réactivité Granulaire[cite: 1]

L'interface graphique est automatiquement mise à jour au moment précis où l'état interne de vos données change[cite: 1].

📦

Empreinte Minimale[cite: 1]

Un coût de bundle ultra-réduit (~40 kB non gzippé) pour un chargement immédiat et une exécution ultra-rapide[cite: 1].

🛠️

Store Réactif Intégré[cite: 1]

Gérez l'état global de votre application simplement avec le système de Store basé sur les Proxies ES6[cite: 1].

🌐

100% Web Standards[cite: 1]

Bâti nativement sur l'API officielle Web Components (Custom Elements, Shadow DOM, HTML Templates)[cite: 1].

Exemples de Code Pratiques

Découvrez la simplicité de mise en œuvre d'AutoUI.

Créer un Web Component avec AutoElement[cite: 1]

Exemple de carte utilisateur personnalisée avec Shadow DOM encapsulé[cite: 1] :

import { AutoElement } from 'autoui-js';[cite: 1]

class UserCard extends AutoElement {[cite: 1]
    static get observedAttributes() {[cite: 1]
        return ['name', 'role'];[cite: 1]
    }[cite: 1]

    render() {[cite: 1]
        const name = this.getAttribute('name') || 'Invité';[cite: 1]
        const role = this.getAttribute('role') || 'Membre';[cite: 1]

        return `[cite: 1]
            <style>[cite: 1]
                :host { display: block; padding: 12px; background: #1e293b; border-radius: 8px; }[cite: 1]
                .title { color: #38bdf8; font-weight: bold; }[cite: 1]
            </style>[cite: 1]
            <div class="user">[cite: 1]
                <div class="title">${name}</div>[cite: 1]
                <small>${role}</small>[cite: 1]
            </div>[cite: 1]
        `;[cite: 1]
    }[cite: 1]
}[cite: 1]

customElements.define('user-card', UserCard);[cite: 1]

Gestionnaire d'État (State Store)[cite: 1]

Mise à jour automatique de vos vues grâce aux proxys réactifs[cite: 1] :

import { createStore } from 'autoui-js';[cite: 1]

// 1. Initialisation du Store[cite: 1]
export const store = createStore({[cite: 1]
    counter: 0,[cite: 1]
    theme: 'dark'[cite: 1]
});[cite: 1]

// 2. Écouter les mises à jour[cite: 1]
store.subscribe('counter', (newValue) => {[cite: 1]
    console.log(`Compteur mis à jour : ${newValue}`);[cite: 1]
});[cite: 1]

// 3. Modifier la valeur (UI synchronisée automatiquement)[cite: 1]
store.counter += 1;[cite: 1]
