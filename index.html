AutoUI est un framework JavaScript UI modulaire, ultra-léger et autonome, conçu sans dépendances tierces ni étape de build obligatoire.

Démarrer via CDN Voir sur GitHub

Pourquoi choisir AutoUI ?

⚡

Zero Build Required

Incorporez-le directement via une simple balise <script> dans votre fichier HTML. Aucun outil comme Vite ou Webpack n'est exigé.

🔒

Shadow DOM Encapsulé

Chaque composant conserve ses styles CSS isolés pour éviter toute interférence de style avec le reste du document.

🔄

Réactivité Granulaire

Met à jour l'interface utilisateur instantanément et de façon ciblée lors de toute modification d'état.

Installation Rapide

Importation direct via CDN

Ajoutez la balise suivante à votre document HTML pour utiliser la dernière version buildée d'AutoUI :

<script src="https://cdn.jsdelivr.net/gh/marcisrael25/autoUI@main/autoui.min.js" defer></script>
