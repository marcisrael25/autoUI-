Documentation AutoUI

Bienvenue dans la documentation officielle d'AutoUI v10.0. AutoUI est un framework léger conçu pour accélérer le développement d'applications Web à l'aide des standard Web Components modernes.

Points Forts : Encapsulation CSS native via Shadow DOM, rendu ultra rapide, zéro configuration webpack ou build compliquée nécessaire.

Installation

Pour intégrer AutoUI dans votre projet, insérez simplement la balise de script CDN suivante dans l'en-tête (<head>) de votre fichier HTML :

HTML 
<script src="https://cdn.jsdelivr.net/gh/autoui/autoui@v1.0.0/dist/autoui.min.js" defer></script>

Utilisation Rapide

Une fois le script inclus, vous pouvez directement employer les balises personnalisées fournies par le framework dans le corps de votre document.

Composant <ui-app-shell>

Le composant conteneur principal qui structure la mise en page générale de l'application et gère l'état global du thème.

Composant <ui-smart-form>

Un formulaire intelligent réactif avec validation en temps réel automatique des champs de saisie.
